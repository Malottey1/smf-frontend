# @numeric/brand-corporate

Brand assets for the **Numeric Technologies** corporate identity: logo
SVGs, self-hosted woff2 fonts, and design tokens (colour, type scale)
used by `apps/www`.

This package is deliberately **not** consumed by `apps/smf-frontend`.
GxP Console (the product) keeps its own distinct visual system — deep
navy, teal, IBM Plex — defined in `apps/smf-frontend/src/design-system`.
The only element shared between the two systems is the monogram, which
is designed to work standalone in both (see `src/logo/`).

Status: awaiting identity approval (monogram concept + palette
direction). Populated once those are picked — see the brand sheet
(`BRAND-SHEET.md`, added at that point) for usage rules.
